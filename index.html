Junior Engineer Walkthrough

Follow these screens in order to prepare a Class 3 FEED estimate. Blue values are entered from the 60,000 m³ crude-oil example; amber values are estimating assumptions until a GAD or approved data sheet confirms them.

Guided example
Start here: this walkthrough produces a FEED screening estimate, not a fabrication design. For the 66.00 m drawing-based tank, Engineering will correctly remain HOLD while the Class 3 estimate may be SCREENING.
1

Design basis

Enter Class 3 Screening mode; quantity 10; nominal and stored capacity 60,000 m³; design/hydrotest level 17.75 m; SG 0.888; temperature 65°C; MDMT 11.3°C; wind 234 km/h; seismic selected; EFR / double deck.

For the drawing-based example, use the approved diameter 66.00 m and shell height 19.50 m. Do not overwrite it with inferred 65.60 m unless the drawing dimension is unavailable.

2

Still on Design basis: materials and courses

Select ASTM A537M Class 1, API material group VI, bottom-shell CA 3.0 mm, other-shell CA 1.5 mm, bottom/annular CA 3.0 mm, roof CA 1.0 mm, and 2.5 m target course height.

Use the expanded plate series through 50 mm and 8% appurtenance allowance; click “Generate courses.”

3

Shell: review, do not re-enter

This screen is the output review. Check the course thicknesses and confirm the visible label says SCREENING PROXY, not a code design release.

4

Bottom & annular

Tick “Force annular.” For this example use 14 mm annular thickness and 900 mm radial width.

These values are not on the supplied datasheet; replace them when the GAD is available.

5

Roof, wind, pressure, seismic, openings

For EFR, the fixed-roof screen is not applicable. Leave unverified wind-girder and opening weights at zero, review pressure/anchorage, and retain the seismic review. Enter 0 kg/m² on Floating roof to use the disclosed 115.8 kg/m² double-deck screening basis.

6

Weight / MTO and Cost intelligence

Click Run design. Review Core MTO, complete empty weight and Class 3 range. On Cost intelligence, keep 2026, raw-steel override 0, calibrated-weight basis, -20% / +30%, and ground reference unticked.

API 650 §5.4 / §5.5

Class 3 automatic selection

When selected, TankM requires an annular plate for a large Class 3 tank, calculates its thickness from the screening table, and rounds calculated radial width up to the next 100 mm. This is a FEED screening assumption, not a drawing release.
This is an owner estimating rule only. It does not replace API 650 or an approved project/GAD annular requirement. It applies only in Class 3 Screening mode.

Governance interpretation

Do not optimize every tank to 0% error. The primary product objective is a governed Class 3 estimate with high hit rate and controlled bias.
The 20 m IFR tank is calibration data. Its exact reproduction is an in-sample check only.
Legacy API edition is recorded as metadata. this release does not apply a blind code-vintage weight multiplier because project specification, CA, roof configuration and fabrication practice can dominate the observed difference.
